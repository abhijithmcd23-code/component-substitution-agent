# Resistor substitution rules (synthetic teaching knowledge base)

- Resistance value must match the original nominal resistance for this prototype.
- Candidate tolerance should be equal to or tighter than the original tolerance.
- Candidate power rating must be equal to or greater than the original power rating.
- Candidate maximum voltage must be known and equal to or greater than the original maximum voltage.
- Candidate operating temperature range must cover the original operating temperature range.
- Package must match for this prototype.
- If a critical specification is missing, do not approve the candidate. Retrieve more evidence once; if still missing, return INCONCLUSIVE.
- These rules are simplified educational examples and are not a substitute for datasheet review or engineering approval.
